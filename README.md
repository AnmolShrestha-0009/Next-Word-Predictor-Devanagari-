# Nepali Next-Word Predictor

A lightweight next-word prediction model for Nepali text. It uses an LSTM whose word embeddings are initialized from pretrained **NepaliBERT**, with a small Streamlit app for interactive demos.

## Overview

This project trains a word-level next-word predictor on a corpus of Nepali news articles (title, summary, and body text). Given the last few words of a sentence, the model returns the top-N most likely next words with their softmax probabilities.

Each vocabulary word's embedding is initialized from the pretrained [`Rajan/NepaliBERT`](https://huggingface.co/Rajan/NepaliBERT) model by mean-pooling the embeddings of its WordPiece sub-tokens. This gives the LSTM a head start on Nepali semantics instead of learning embeddings from scratch.

## Key Features

1. **Pretrained embeddings:** word embeddings are derived from NepaliBERT's input embedding layer rather than random initialization.
2. **Devanagari-aware preprocessing:** HTML stripping, punctuation and digit cleanup, sentence splitting on `।`, and a regex word tokenizer for Devanagari, digits, and symbols.
3. **Top-N predictions with probabilities:** results are ranked by softmax probability and shown in the notebook and the Streamlit app.
4. **Swappable architecture:** the LSTM is a minimal placeholder. Any model that maps `(batch, context_size)` token indices to `(batch, vocab_size)` logits works with the rest of the pipeline.
5. **Lightweight demo app:** a single-file Streamlit app that loads saved artifacts and runs on CPU.

## How It Works

```text
Raw Nepali articles
        │
        ▼
Cleaning + sentence/word tokenization
        │
        ▼
Word-level vocabulary (top-K frequent words)
        │
        ▼
Embedding matrix  ◄── NepaliBERT (mean-pooled sub-token embeddings)
        │
        ▼
(context window → next word) training pairs
        │
        ▼
Embedding → LSTM → Linear (vocab-sized logits)
        │
        ▼
Softmax → top-N next-word predictions
```

## Tech Stack

- **Language:** Python
- **Deep learning:** PyTorch
- **Pretrained model:** Hugging Face Transformers (`Rajan/NepaliBERT`)
- **Data handling:** pandas (parquet input)
- **NLP utilities:** gensim (imported in the notebook), regex-based tokenization
- **Demo UI:** Streamlit
- **Environment:** Jupyter Notebook (GPU recommended for training, e.g. Google Colab T4 GPU)

> The notebook also contains an optional section on MLM fine-tuning of NepaliBERT with cosine-similarity search. It is separate from the next-word predictor and can be skipped.

## Getting Started

### Prerequisites

- Python 3.9+
- `pip`
- Internet access to download `Rajan/NepaliBERT` from the Hugging Face Hub
- Your Nepali news dataset in parquet format (path is set in the notebook)
- A GPU is recommended for training but not required for the demo app

### Installation

```bash
# 1. Clone the repository
git clone https:https://github.com/AnmolShrestha-0009/Next-Word-Predictor-Devanagari-.git


# 2. (Recommended) Create a virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Install demo app dependencies
pip install -r requirements.txt

# 4. Install notebook dependencies (only needed for training)
pip install jupyter pandas pyarrow transformers gensim
```

### Train the Model

1. Open `DEEP_LSTM_finetuned.ipynb` in Jupyter or Google Colab.
2. Update the dataset path in the data-loading cell to point to your parquet file.
3. Run the cells in order: cleaning, tokenization, embedding matrix, training pairs, and training loop.
4. Run the final **Save Artifacts** cell. It creates the `demo_artifacts/` folder.

### Run the Demo App

Place `demo_artifacts/` next to `app.py`, then run:

```bash
streamlit run app.py
```

The app opens in your browser, typically at `http://localhost:8501`.

## Usage

### In the notebook

```python
predict_next_word("नेपाल सरकारले आज", top_n=5)
```

Example output format (values depend on your trained model):

```text
Context: नेपाल सरकारले आज
  1.  पनि          p=7.1
  2. सार्वजनिक         p=5.6
  ...
```

### In the Streamlit app

1. Enter Nepali text in the input box.
2. Choose how many predictions to show (1–10).
3. Click **Predict next word**.

## Configuration

Key parameters live in the notebook:

| Parameter | Description | Default |
|---|---|---|
| `VOCAB_SIZE` | Maximum vocabulary size (most frequent words) | `20000` |
| `CONTEXT_SIZE` | Number of preceding words used as context | `4` |
| `hidden_dim` | LSTM hidden size | `256` |
| `num_layers` | Number of LSTM layers | `1` |
| `freeze_embeddings` | Keep pretrained embeddings fixed during training | `False` |
| `EPOCHS` | Training epochs in the demo loop | `3` |

> If you change the model architecture in the notebook, update the `NextWordLSTM` class in `app.py` and the values in `config.json` to match. Otherwise the saved weights will fail to load.

## Limitations

- Predictions are word-level and limited to the capped vocabulary. Out-of-vocabulary words map to `<unk>`.
- The default training loop is a minimal demo (no validation split).
- Output quality depends on corpus size, training time, and architecture choices.
- Very small Corpus size was chosen(for demonstration purpose only)
- Consist of only 3 epochs due to hardware limitation
